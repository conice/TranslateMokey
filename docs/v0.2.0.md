# v0.2.0 第二阶段实施说明

本文记录第二阶段版本边界；当前实现与验收入口见 [v0.4.0 实施说明](v0.4.0.md)。

## 状态与范围

第二阶段规划的代码能力已实施；真实浏览器安装、接口联调、性能和用户验收仍不是自动化测试可以替代的发布授权。产品蓝图以 [README](../README.md) 为准，第一阶段功能与存储边界见 [第一阶段说明](v0.1.0.md)。以下为本版新增能力与限制。

| 能力 | 本版实现与边界 |
| --- | --- |
| 双语阅读 | “网页阅读”页开启；支持双语与仅译文模式，原文保留或可恢复；段落内部末尾插入隔离的纯文本译文，不重建链接或原文元素；可暂停、继续、重试失败段落、恢复原文 |
| 可见区域 | 仅派发视口内正文，滚动时继续；使用 IntersectionObserver，缺失时退回滚动/窗口大小事件；不预先发送全部页面 |
| 动态页面 | MutationObserver 监听新增、删除、文字及相关属性变化；150ms 去抖，仅扫描受影响段落，初次扫描按每批 200 个文本节点处理 |
| 页面切换 | 响应写入前核对 URL、节点连接状态及原文；SPA URL 变化至迟约 500ms 停止并恢复，需手动重开；pagehide 取消，BFCache 恢复不自动重发全文 |
| 队列 | 划词与网页阅读共用单并发队列，划词优先但不抢占活动请求；网页最多同时派发 20 个任务，队列最多 100 个等待任务；无自动重试或并发加速 |
| 缓存 | 当前页面内存 LRU，最多 200 条且键和值合计不超过 100 万 UTF-16 代码单元；文本、规范端点、模型、语言、参数与提示版本隔离；更换凭据清缓存；不持久化，不跨标签共享 |
| 网站规则 | 精确域名：手动、自动、禁用；不包含子域名通配或路径规则；独立控制网站标注；禁用时也阻止划词翻译与标注 |
| 生词标注 | 每次、每页首次、每段首次；词后释义、点击展开、下划线词义卡片、仅高亮；动态变化 250ms 局部刷新，跳过脚本译文；已掌握词支持隐藏/淡化/正常显示 |
| 译文样式 | 跟随网页、柔和灰或绿色；支持字号、行距；原文样式不变，不接受任意 CSS |
| 学习跳过 | 可配置已掌握源语言；仅显式源语言跳过，`auto` 不猜测；网站规则可覆盖源语言和目标语言 |

正文按最近的 `p`、标题、列表项、表格单元格、引用、图注以及 `div/section/article` 收集。嵌套块分别处理；不改写原文的行内结构，但译文不重建链接或强调格式。超过 10000 字符的单个文本块跳过，不自动切块。混合语言交给服务判断；不凭网页语言跳过请求。

第二阶段代码范围已完成。跨标签词条匹配、CJK 分词、iframe、网站 Shadow DOM、PDF/画布内容属于 README 中明确的兼容边界或第三阶段能力，不作为第二阶段网页阅读完成条件。长页面持续变动时的真实性能及页面样式冲突仍需实测。

## 安装与使用

Node.js >=20，零新增依赖，无须 `npm install`：

```sh
npm run build
npm test
npm run check
```

将生成的 `dist/TranslateMokey.user.js` 导入用户脚本管理器，安装方法与 GM API 要求沿用第一阶段。未配置远端更新地址，未部署或发布。

1. 在设置中确认服务、模型、语言与凭据；旧版设置和词条保持版本 1，缺失新增字段使用默认值，无清空或迁移。
2. 打开“网页阅读”→“开启双语阅读”，或选择“仅启用逐段翻译”；核对接收方、文本范围和持续费用提示后确认。双语/仅译文模式可在设置或阅读页切换，逐段模式只在点击段落按钮后发送。
3. 暂停会取消尚未完成的网页任务、保留已有译文；恢复原文会取消任务并移除译文。关闭面板不等于停止阅读。
4. 网站默认为手动；设置当前域名为自动后保存，需额外授权。保存不会立即发送请求，下次加载时才自动开启。保存服务设置时会重新确认所有自动域名的接收方。取消确认不保存设置。
5. 修改设置、密钥或收到其他标签的数据变更时停止阅读；同域其他页面与其他标签使用保存的规则，正在阅读的标签不会静默重启。

## 安全边界

- 全文阅读不受划词“关闭弹窗”影响：手动开启始终确认；自动开启仅依据用户已保存的域名授权。持续滚动、动态内容可能产生持续费用。
- 排除输入框、编辑区域、代码、隐藏属性、`aria-hidden`、`translate="no"`、脚本界面与译文；正文所在块还需通过可见性检查。不能保证识别所有站点自定义编辑器或 CSS 隐藏的行内敏感文本，私密站点应设置禁用。
- 只发送正文文本，不发送页面 URL、标题、HTML 或上下文元数据；网页中可见的私人正文仍会发往所配置的服务。
- 网络沿用匿名、拒绝重定向、HTTPS 与 30 秒超时；管理器真实行为未验证。缓存不会存入日志、备份或 GM 存储，密钥不放进缓存键。
- 译文与释义通过 `textContent` 展示，不执行服务返回的 HTML。恢复原文仅删除脚本自有节点；暂停/取消不能撤回服务端已收到的请求或已发生的费用。
- JSON 仍仅备份生词本，不包含网站规则、缓存、服务设置或凭据。
