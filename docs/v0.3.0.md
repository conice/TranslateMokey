# v0.3.0 第三阶段实施说明

本文记录 v0.3.0 的学习、词典与协议能力。后续界面及设置流程变化、当前安装与验收入口见 [v0.4.0 实施说明](v0.4.0.md)。

## 状态与范围

第三阶段已启动，已实现本地学习闭环，以及自定义词典、发音和两种新增服务协议，不代表整个阶段完成或发布。既有翻译与网页阅读能力沿用 [第二阶段说明](v0.2.0.md)，产品蓝图见 [README](../README.md)。无新增依赖，沿用已有 GM 跨域权限；新增词典和发音功能不会自动请求。

| 能力 | 本版实现与边界 |
| --- | --- |
| 词形关联 | 生词本编辑原形与最多 20 个关联词形；仅手动确认，不做语言学推断；原形和词形均参与区分大小写的完整词匹配 |
| 匹配冲突 | 精确原词优先于关联词形；多个候选词条共用同一关联词形时跳过该词形；语言过滤、短语优先及单文本节点限制不变 |
| 多义项 | 默认释义仍使用原有 meaning/example，最多补充 20 个其他释义/例句；可编辑、确认移除、交换默认义项；标注与复习使用默认义项，不自动判断语境 |
| 重复收藏 | 确认后补充其他义项，不再覆盖默认释义、备注、词形与复习记录；相同释义和例句组合不重复添加 |
| 复习卡片 | 复习页按到期时间选词，每轮 1–100 条，默认 20 条；正向/反向卡片，显示答案后才能评分；所有语言均参与，无后台提醒 |
| 间隔 | 认识连续按 1/3/7/14/30/90/180 天，上限 180 天；模糊为 1 天，不认识为 10 分钟；两者均重置连续进度，下次认识从 1 天开始 |
| 学习状态 | 无记录显示未学；已评分显示次数及下次时间；已掌握词不参与复习，不自动判定掌握；手动标记为未掌握时，有复习记录需先确认重置，随后立即进入待复习列表 |

这是透明的固定间隔调度，不是 Anki、SM-2 或 FSRS，不宣称记忆保持率。按 UTC 时间点加固定时长，1 天等于 24 小时，不按本地午夜重置；界面用本地时间显示。依赖设备时钟，回拨可能推迟到期，不自动纠正。每轮数量不是跨标签或跨日的每日上限。

## 词典与发音

- “词典 / 发音”页默认使用微软 Bing 中国英汉词典：`https://cn.bing.com/dict/search?q={term}`。展示基本释义和英美音标；它是网页解析而非稳定公开 API，可能遇到验证码、地区限制或页面改版。解析失败明确报错，不偷偷切换其他数据源。v0.4.0 起内置项只读，界面不显示其 URL 或解析脚本。
- 查询仅发送用户输入的词/短语（最多 200 字符）；每次查询都需确认，不受翻译“关闭弹窗”影响。v0.4.0 起确认框只显示词典名称，不显示完整接收地址。匿名 GET、30 秒超时、拒绝重定向、不携带翻译 API Key；禁用网站禁止查询。修改输入、关闭面板、保存相关配置、跨标签变更或 pagehide 时取消，并拒绝旧结果。不会自动查询整页词汇。
- Bing 返回的释义通常为中文，不随翻译目标语言自动翻译；结果标明词典来源。可独立收藏，无须先调用模型；收藏时确认源语言及释义语言，已有词补充义项而不覆盖默认含义。新增词的备注保留词典名称和音标；补充义项沿用现有 meaning/example 结构，不额外保存逐义项来源。
- 设置中可保存多个自定义词典并选择当前使用项；v0.4.0 起内置 Bing 与自定义项共用一个下拉框。自定义 URL 必须为 HTTPS，包含 `{term}`，占位符自动 URL 编码且不能用于域名。当前只支持无鉴权 GET，不提供任意请求头、POST 或密钥配置；不要在 URL/JS 中填写秘密。界面隐藏已保存 URL/脚本，但 GM 存储仍是明文。
- JSON 模式返回 `{ "meaning": "释义", "phonetic": "音标", "example": "例句" }`，后两个字段可省略。释义最多 2000 字符、音标 500 字符、例句 2000 字符，响应上限 1 MiB 字符；界面只用纯文本展示。
- JS 模式填写函数体，参数仅为 `responseText` 和 `term`，返回与 JSON 模式相同的对象，可返回 Promise。例如：

```js
const data = JSON.parse(responseText);
return { meaning: data.definition, phonetic: data.pronunciation ?? '' };
```

JS **仅用于响应解析**，不是任意用户脚本插件：在无同源权限的 `sandbox="allow-scripts"` iframe 内创建 Worker，CSP 禁止网络，不能访问页面 DOM、父窗口、GM 存储或翻译凭据；2 秒无结果则销毁隔离环境。保存时确认可信代码，保存不执行。浏览器 CSP 或 Worker 不可用会报错，不回退到主页面 `eval`。这些隔离行为仍需真实浏览器验证；不要运行不可信代码，超时不是内存资源配额。

发音采用 Web Speech API，只选择 `localService === true` 且语言匹配的语音；缺少语音包时明确报错，不改用联网语音。可在翻译、生词本、词典和复习答案中触发，支持停止，关闭面板停止脚本启动的播放。不播放 Bing 音频，也不请求第三方 TTS。语音是否真正离线依赖浏览器/系统实现，尚未通过真实设备网络抓包验证。`auto` 不猜语言，使用词典页明确设置的发音语言（本页默认 `en-US`，不持久化）；语音列表异步加载时可稍后重试。

## 新服务协议

在设置中选择协议，填写相应基础地址、模型和 API Key，然后保存（v0.4.0 起改为自动保存，见新版本说明）。v0.4.0 起可保存多个 API 配置并选择当前项，填写地址与 Key 后可拉取模型；API Key 按 API 标识独立保存。切换协议或 API 不会自动发送翻译文本；Index 预设仍为 OpenAI 且只读。旧配置缺少 protocol 时默认 OpenAI，旧地址 Key 仅作为兼容回退读取。

| 协议 | 地址示例与请求 | 鉴权及参数 |
| --- | --- | --- |
| OpenAI Chat Completions | 原有基础地址追加 `/chat/completions` | Bearer；保留现有参数白名单 |
| Anthropic Messages | `https://api.anthropic.com/v1` 追加 `/messages` | `x-api-key`，固定 `anthropic-version: 2023-06-01`；temperature、top_p、max_tokens，max_tokens 缺省 4096 |
| Gemini generateContent | `https://generativelanguage.googleapis.com/v1beta` 追加 `/models/{model}:generateContent` | `x-goog-api-key`，不把密钥放 URL；temperature、top_p、max_tokens 映射为 temperature、topP、maxOutputTokens |

均为非流式；模型 ID 由用户填写，不假定某个模型可用或支持全部参数。Gemini 模型不含 `models/` 前缀或路径。Index 的 `chat_template_kwargs` 不能跨协议沿用，切换后需删除不支持的参数。Anthropic 使用已核查仍列出的旧协议版本，不自动升级到新版本，不开启额外浏览器直连标志；管理器真实请求兼容性待验收。

划词和网页阅读共用适配器；缓存加入协议与实际端点隔离，凭据按实际端点存储（Gemini 换模型后需单独配置）。Anthropic 合并 text 块，Gemini 排除 thought 块；拒绝截断、被阻止、空白或结构错误的响应，不把思考块当译文。不自动重试或故障转发。真实服务鉴权、费用和模型联调未执行。

## 数据与兼容性

- GM 存储包装版本仍为 1，词条 ID 不变，不启动批量迁移、不清空旧数据；旧词条无需新增字段即可读取。
- 可选字段为 lemma、forms、senses、review；复习仅记录累计次数、连续间隔档位、最近反馈和上次/下次时间，不保存完整事件历史。
- JSON 导出改用格式版本 2，保留新增字段；导入接受版本 1 和 2，未知版本拒绝。旧脚本会拒绝版本 2 备份，避免导入时静默丢失学习信息。
- 生词本备份仍不含设置、缓存、日志、密钥；导入只补充新词，重复词条跳过，不合并复习记录。建议升级前导出备份。不要用旧脚本编辑新增字段的词条，否则旧版白名单会丢弃这些字段。
- 词典配置独立保存在 `tm:dictionary`，v0.4.0 起使用 `{ selectedId, profiles }` 保存多个配置；不进入生词本备份，不导出 JS、词典 URL 或原始响应；临时查询结果关闭后清除。API Key 保存在 `tm:secret:api:<id>`，不进入备份，且 GM 存储不提供加密。不要用旧版本脚本修改新协议设置，以免协议字段被丢弃。
- 评分前重新读取并比较词条，拒绝已删除、已修改、重复评分或尚未到期的卡片。GM API 无事务或原子比较交换；两标签真正同时写同一词条仍可能最后写入获胜，不承诺强一致性。原有编辑界面也不提供事务锁。
- 存储错误会显示，评分失败不会推进卡片；若词条写入成功但跨标签通知写入失败，可能已保存而界面报错，请刷新后确认，不盲目重复评分。


## 使用与验证

Node.js >=20，无须安装依赖：

```sh
npm run build
npm test
npm run check
```

安装产物为 `dist/TranslateMokey.user.js`。打开生词本编辑词形与义项，在“复习”页设置每轮数量及方向后开始；更改数量/方向后点击刷新生效。新增、导入或编辑词条后重新打开复习页/点击刷新读取最新数据。到期时间到达时不会自动刷新。

自动化覆盖旧备份、新字段白名单与往返、词形冲突、反馈间隔与上限、UTC 跨日、时间回退、过期卡片与删除保护、持久化失败，以及打包界面的编辑、重复收藏和复习操作。新增词典 URL/响应校验、取消与迟到结果、隔离消息校验及生成 Worker 代码执行、发音语音选择、协议请求与响应测试。替身和 Node VM 不等于浏览器 CSP/Worker 安全验收；命令结果以本次终端执行为准。

真实浏览器安装、手机触摸、跨标签竞态、接口联调和用户验收均未完成，未部署、未发布。手动验收沿用 [reading.html](../test/fixtures/reading.html)，新增第三阶段清单。浏览器兼容性候选与现有待验收项沿用第二阶段说明。

2026-11-05 执行 `npm run verify:browsers`：当前环境的 PATH 未找到 Chrome/Edge/Firefox/Playwright 可执行文件；因此未执行真实浏览器中的 JS 沙箱、词典 DOM 解析、语音或管理器安装测试，不以 Node 替身通过代替。
