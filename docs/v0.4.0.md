## 状态与范围

## 界面重构

依据 [iOS 27 设计参考](ios-27-design.md)及 Apple 官网的内容层级重做整个用户脚本界面，服务协议与词条结构不变；联网确认改为显示当前配置名称，不显示地址、模型或凭据；选区查询流程与默认来源设置按下述规则更新。不增加依赖，也不宣称实现原生 Liquid Glass。

- 采用白色/深色实色内容层、轻量导航和单一蓝色主操作；不使用玻璃模糊或装饰性内容卡片，正文、表单和词条依靠留白、字号层级与细分隔线组织。具体圆角、阴影和尺寸为项目值，不是 Apple 硬性规范。
- 选中文字本身不联网；点击“翻译选区”后立即按默认来源查询，仍先执行适用的联网确认。AI 与词典共用一个原文输入框、结果区域和释义编辑表单；原文始终可编辑，释义默认只读，点击编辑图标后修改，完成编辑回到结果。收藏采用当前来源编辑后的释义，修改原文或查询语言后双方旧结果均失效。无选区时提供手动输入。
- 默认来源可在“设置 → 默认查询与语言”选择 AI 或词典，选择后自动保存，新增 `lookupProvider` 字段，旧设置缺失时为 AI，不迁移或清空数据。旧 `autoTranslate` 值保留但不再控制主动点击选区后的查询，界面移除该冗余开关。AI 遵守 `hideFeePopup`；词典默认每次独立确认，可由“词典来源与解析”中的 `hideDictionaryFeePopup` 关闭，两个开关互不影响。词典超出 200 字符或失败时不会自动向 AI 转发，需主动切换来源。
- 设置无需保存按钮：下拉框、开关在更改时保存，文本框在更改后失焦时保存；显示微调的数值与颜色在输入有效值时即时保存。独立设置分别校验，坏的服务草稿不阻止字号等设置保存；写入失败明确提示未保存。自动网站授权与自定义 JS 确认保留，拒绝时恢复已保存值；收藏、词条编辑仍使用显式提交，避免误改生词本。
- 字号采用[官网核对与项目取值](ios-27-design.md#apple-官网字号核对与项目取值)。译文字号与行距立即作用于查询结果及已有网页译文，不停止阅读、不重发请求；服务、语言和网站规则变化仍会停止阅读，下次启动按新配置执行。
- 设置仍在单个折叠组“网页阅读与标注”内，以“标注”和“网页阅读”两个标题分节，不新增独立分组。标注提供释义字号（0.5–2em）、释义颜色、原词与释义间距（0–2em）及高亮颜色；仅高亮时隐藏释义外观控件。网页阅读提供译文字号（0.75–2em）、行距（1.2–3）、颜色及原文与译文间距（上下留白，0–3em）；数值步长为 0.01，均保留快捷预设，颜色支持自选。微调即时自动保存并更新本地交互示例，不发送请求；已保存的显示参数保留，缺省字段采用当前默认，标题与阅读默认排版参考 [Apple 官网核对与项目取值](ios-27-design.md#apple-官网字号核对与项目取值)。“刷新网页标注”位于标注节，“已掌握语言”归网页阅读节。两节分别恢复显示默认（含标注频率、样式、已掌握词显示或阅读模式），保留标注总开关、另一节、已掌握语言和网站授权。
- 主导航为“查询、学习、设置”：查询内通过“文本 / 网页”切换范围，学习内切换生词本/复习。查询来源“AI / 词典”为独立文字选择组；原文下方仅放发音/停止和查询/取消/重试图标；结果标题旁放编辑/完成和收藏图标，不混入来源选择。来源采用 13px 次要标签，译文保持 16px 标准正文；空内容与错误提示不套译文样式，无结果时禁用编辑和收藏。来源选中除颜色外还有下划线，操作组允许换行，图标采用内联线条 SVG，提供 `title` 与 `aria-label`，点击区域至少 44px。来源切换不联网，会取消在途查询；各来源结果与编辑草稿保存在当前面板会话内，切回可查看，不写入持久化查询历史。
- 网页翻译保留独立任务和授权范围，不向词典发送网页内容；保留“开启双语阅读 / 仅启用逐段翻译”明确文字入口。暂停/继续合并为一个状态图标，双语/仅译文合并为显示方式选择，重试和恢复原文采用图标；未启动时禁用任务控制。段落内“翻译本段 / 重新翻译”分别使用语言符号与回转箭头：20×20 CSS px SVG、1.8 描边、44×44 CSS px 点击区域，保留 `title` 与 `aria-label`，不改变可信点击校验或重译逻辑。设置中的“打开网页阅读”保留为同一页面的快捷入口。语言、来源说明、费用确认和错误状态保留文字，发音语言与低频选项折叠展示。
- 移除普通内容卡片、输入框外框和大面积圆角，主要依靠留白、文字层级和细分隔线组织内容；仅保留主操作强调色、外层面板及必要的系统对话框。状态不再绘制独立卡片。
- `ⓘ` 放在对应的发送范围、费用确认、解析格式、发音、备份或词形编辑等功能旁，不再放在整页标题处。点击通过原生 `dialog` 展示该主题说明；弹窗有读屏名称和关闭按钮，Escape 只关闭说明并恢复触发按钮焦点。依赖 `dialog.showModal()`，真实焦点限制与读屏表现待验收；词条元信息收进“词条详情与管理”，实时状态直接显示。
- 统一按钮、输入框和下拉框样式；按钮至少 44 × 44 CSS px，复选框保持紧凑并通过整行标签扩大点击区域。文字允许换行，不将网页字号等同于原生 Dynamic Type。
- 桌面采用右下浮动面板，手机采用四周留边的底部面板，预留安全区；面板打开时隐藏浮动入口，避免遮挡。支持 Visual Viewport 的浏览器在未缩放时根据可视高度和偏移调整软键盘避让；不支持时回退至动态视口或普通视口高度。
- 保持非模态面板，不锁住宿主网页焦点。导航切换不主动聚焦输入框；选区打开时聚焦非输入容器，不主动唤起软键盘；Escape 关闭并恢复打开前焦点。
- 提供深色、减少透明度、增强对比度、强制颜色和减少动态效果的 CSS 分支，不新增动画。不假设浏览器能读取 iOS Liquid Glass 外观滑块。

界面自动化检查导航状态、焦点恢复、模拟软键盘视口变化、加载与取消反馈、静态配色对比度及降级样式声明。真实 CSS 渲染、实际对比度、系统偏好支持、文本缩放、VoiceOver 和手机软键盘表现仍需真机验收。

## 多 API、多词典与提示词

- AI 服务页顶部用下拉框选择当前 API。内置 Index 配置只读，不能编辑、删除或设置凭据；其地址、模型和凭据不显示。可添加最多 20 个自定义 API，选中项立即用于划词翻译、网页阅读和费用确认，切换本身不发送请求。
- 自定义 API 需填写名称、协议、HTTPS 地址和 API Key；地址与 Key 就绪后自动拉取模型，失败时可手动填写模型 ID。保存前可重新拉取；编辑已有 API 时 Key 输入框保持空白，仅提示是否已保存，不回显旧值。
- API Key 按 API 标识独立保存在 `tm:secret:api:<id>`，不再以服务地址作为主键。删除自定义 API 会清除对应 Key 并回到内置 API；清除 Key 后不会回退到旧地址凭据。旧设置中的自定义 API 迁移为 `legacy:api`，旧地址 Key 仅作为兼容回退读取。
- 词典页同样用下拉框选择当前词典。内置微软 Bing 词典只读，URL 与解析脚本不显示；可添加最多 20 个自定义 JSON/JS 词典，编辑、删除和切换均不自动请求。词典查询默认在发送前确认，可关闭“关闭弹窗（不再显示词典请求前的费用确认）”；关闭后直接发送当前词并可能产生费用，不影响 AI 费用确认、网页阅读或 JS 保存确认。查询确认只显示词典名称，JS 保存仍要求可信代码确认，查询仍在禁网隔离环境中执行解析。
- 脱敏覆盖设置摘要、联网确认、翻译/词典状态、诊断日志和导出内容；词典结果不保存接收 URL，内置配置的地址、模型、脚本与凭据不进入这些出口。脱敏不是加密：自定义 API 地址、词典 URL/脚本和 Key 仍以明文保存在 GM 存储中，Key 不进入生词本备份。
- AI 服务组提供提示词模式。内置提示词只读，要求模型只输出最符合上下文的一个最常用译文，不显示备选、解释、音标、词性或说明；模型仍可能不遵守，脚本不按标点猜测截断。自定义提示词必须包含 `{text}`，可使用 `{target}`、`{source}`、`{sourceInstruction}`；首次切到自定义时以内置模板预填，之后可编辑。
- 提示词模式与自定义内容随设置自动保存。更改实际生效的提示词会停止网页阅读、清空翻译缓存并影响后续 AI 查询，不发送请求；未启用的自定义草稿不拆分内置提示词的缓存。缓存键按实际生效的提示词隔离，不使用草稿值。


## 悬浮入口与字号

- 设置 → 默认查询与语言 → “右下角‘译’按钮功能”按项自动保存，可选文本查询（默认）、网页翻译、生词本、复习、快捷菜单。旧设置缺少此项时仍进入文本查询；有选中文字时始终优先按默认来源查询选区。
- 快捷菜单固定提供文本查询、网页翻译、生词本、复习和设置；再次点击“译”、点击外部或按 Escape 收起。网页翻译入口仅打开现有页面，不自动发送正文，开启阅读仍使用原有确认流程。
- “译”入口的可见背景从 52px 缩至 32px，点击区域仍至少 44px；背景使用内缩 6px 的伪元素和轻阴影，选区提示变长时横向自适应。
- 桌面与手机采用紧凑文字层级，具体字号统一维护在[项目取值](ios-27-design.md#apple-官网字号核对与项目取值)，不将官网宣传标题直接套用到工具面板。
- 已有网页译文更新字号、行距、颜色或显示模式时保留内容和节点，不重新请求；后续译文沿用新样式。查询结果同步字号和行距，网页译文颜色设置不改变查询界面配色。

## 自动保存与数据边界

- 删除“保存设置”和“保存词典配置”按钮；首次加载和单纯打开设置不会写入数据或发起请求。
- 普通设置按项保存；API 配置、网站规则按组校验，词典配置独立校验，API Key 使用独立保存/清除操作。JSON、地址或其他值非法时保留草稿并显示未保存；重新打开设置会读取已保存值，不持久化非法草稿。
- 更改自动网站授权涉及的服务、语言或规则时仍需确认。仅调整字号等外观不会重复授权；确认取消恢复已保存设置。自定义 JS 保存仍需信任确认，保存不执行代码。
- GM 存储包装版本仍为 1，生词本备份版本仍为 2；新增默认来源字段缺失时按 AI 处理。设置新增 `selectedApiId`、`apiProfiles`、`promptMode`、`customPrompt` 与 `hideDictionaryFeePopup`，提示词模式缺失时默认内置，词典确认开关缺失时默认保留；词典存储新增 `selectedId` 与 `profiles`；旧自定义 API/词典按兼容路径读取，旧凭据、词条及复习数据不删除。
- 本次自动保存仅覆盖设置。收藏、词条编辑、删除、备份导入和凭据修改仍保留各自明确的提交或确认流程。

## 构建与安装

Node.js >=20，无新增依赖：

```sh
npm run build
npm test
npm run check
```

将生成的 `dist/TranslateMokey.user.js` 更新安装到现有用户脚本管理器，确认版本为 0.4.5 后刷新目标网页。不要仅修改仓库源码而继续运行旧的已安装脚本。产物由源码生成且不纳入 Git；没有配置远端更新地址，源码提交与推送不等于部署用户脚本或创建发布，安装更新仍需手动替换产物。
