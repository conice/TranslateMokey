# v0.1.2 第一阶段实施说明

本文记录第一阶段版本边界，不代表当前版本状态；当前实现与验收入口见 [v0.2.0 实施说明](v0.2.0.md)。

## 状态与范围

已实现第一阶段核心闭环的初版代码，尚未完成真实浏览器安装、接口联调或用户验收，不是发布声明。产品长期规划以 [README](../README.md) 为准。

| 能力 | 本版实现与限制 |
| --- | --- |
| 翻译接口 | Index 预设及一个可编辑的 OpenAI 兼容配置；HTTPS、非流式 chat.completions；支持有限的附加参数，不支持任意请求头、任意 JSON 或多服务管理 |
| 源语言 / 目标语言 | `auto` 由服务根据待翻译文本判断；支持手动语言代码与临时修改；不声称已获得源语言识别标签，不自动根据页面语言跳过请求 |
| 划词翻译 | 顶层页面选区入口、可选划词自动翻译、手动粘贴、可编辑译文、重试、取消；默认发送前确认费用，可在设置中关闭该弹窗；最多 10000 字符，不发送上下文 |
| 生词本 | 收藏单词/短语（原词最多 200 字符、释义最多 2000 字符）、编辑释义/例句/备注、搜索、重复覆盖确认、删除及本次撤销；最多 5000 条 |
| 本地标注 | 默认关闭；区分大小写的完整词精确匹配、短语优先、目标语言过滤；指定源语言优先，否则参考页面 `lang`，`auto` 词条表示源语言未确认；可手动刷新 |
| JSON 备份 | 版本 1；仅备份生词本，不含服务配置和密钥；导入前验证并预览新增/重复数，只补充不覆盖；文件上限 5 MiB，超限导出明确拒绝 |
| 桌面 / 手机界面 | 隔离 Shadow DOM、桌面浮窗与手机底部面板、系统明暗主题、44px 按钮、键盘焦点和 Escape 关闭；不依赖悬停；实际浏览器体验待验收 |

没有实现全文翻译、动态页面自动标注、跨标签短语、CJK 分词、词形扩展、发音、复习、历史、网站规则、跨设备同步、多服务切换或自动重试。页面新增内容需点击“刷新网页标注”或脚本菜单。iframe、站点 Shadow DOM、画布和 PDF 不扫描。普通词条按 `原词 + 源语言 + 目标语言` 去重，不实现多义项管理。

## 构建与安装

开发需要 Node.js >=20。无运行时或构建依赖，无须 `npm install`：

```sh
npm run build
npm test
npm run check
```

构建输出：`dist/TranslateMokey.user.js`（忽略 Git 跟踪）。在用户脚本管理器中新建脚本并粘贴该文件内容，或用管理器支持的本地导入方式安装。没有配置远端自动更新 URL，没有执行发布。

首轮候选验收组合为桌面 Chrome + Tampermonkey、Android Firefox + Tampermonkey；具体版本、扩展可用性与结果待实测记录。这不是兼容承诺。其他管理器必须提供传统同步 `GM_getValue`、`GM_setValue`、`GM_listValues`，以及 `GM_addValueChangeListener`、`GM_registerMenuCommand`、`GM_xmlhttpRequest`；不支持仅有 `GM.*` Promise API 的环境。

1. 打开普通 HTTP(S) 网页，点击右下角“译” → “设置”。
2. 保留 Index 示例预设，或填写服务的 `/v1` 基础地址（也可填写完整 `/chat/completions` 地址）、模型及允许的附加参数。Index 鉴权、可用性和条款未核实。
3. 点击“设置 / 清除 API Key”，通过浏览器原生输入框录入。输入框可见，不回填页面 DOM；不要在旁人可见场景输入。设置服务地址不同，密钥分开保存；旧地址密钥不会自动删除。
4. 保存设置；选取正文或手动粘贴，点击翻译，核对接收方后确认。管理器可能另行请求跨域授权。
5. 编辑简短释义后收藏，在设置中开启本地标注。原文或语言修改后需重新翻译才能收藏，避免保存不对应的结果。

设置新增两个独立复选框，均默认不勾选，旧设置也按关闭处理：

- **自动翻译**：选中正文后，点击“翻译选区”打开面板即开始翻译，无须再点“翻译 / 重试”。仅选中或更改选区不会打开面板或发送请求；没有选区时打开入口也不会自动翻译输入框中的旧内容。
- **关闭弹窗**：跳过翻译请求前“可能产生服务费用”的确认，不关闭译文面板，也不影响删除、覆盖等确认。仍在请求状态中显示接收端、模型、字符数与费用提示。关闭提示不意味着服务免费。

同时勾选并保存后，点击“翻译选区”会打开面板并直接发送选中文本，不再逐次询问。自动翻译开启但未关闭弹窗时，仍需确认后才发送；手动翻译同样遵循弹窗开关。

附加参数白名单：`temperature`、`top_p`、`max_tokens`、`max_completion_tokens`、`chat_template_kwargs.enable_thinking`。语言代码格式校验不代表服务支持该语言。

## 安全与存储边界

- 自定义域名需要 `@connect *`。这扩大管理器授权范围。默认点击翻译并确认后发送；显式开启自动翻译后由点击“翻译选区”触发，勾选关闭弹窗后不再逐次确认。只向当前端点发送选区/输入文本，不自动调用连接测试、不发送页面 URL、标题或上下文。
- 请求设置 `anonymous: true`、`redirect: 'error'`、30 秒超时，不添加 Cookie 或 User-Agent，不切换备用服务。管理器是否正确执行这些选项需要实际验证；若目标管理器无法阻止重定向，不应输入真实密钥或私密文本。
- 密钥以 `tm:secret:<规范端点>` 单独存储，只用于请求头，不进入 DOM、日志或备份。存储不是加密保险箱；浏览器原生输入框不提供密码遮罩。仅使用可信脚本管理器和可信网页。
- 翻译、收藏释义与导入字段只通过 `textContent` / 表单值展示，不解析 HTML。来源 URL 存储前移除查询参数和片段，但标题、路径、例句仍可能包含私密信息，导出前应自行检查。
- 设置与每个词条携带数据版本；未知版本报错，不静默覆盖。按词条独立存储避免不同标签页新增相互覆盖，同一词条并发编辑仍为最后写入者生效，不保证事务级冲突处理。
- 删除使用本地墓碑记录支持通知，不是安全擦除；本次撤销存在当前页面提示中。导入不是原子事务，存储失败会显示已写入条数，重试跳过已有条目。存储上限由管理器决定。
- 标注分批扫描，每批 100 个文本节点；只移除自有标注并合并仍相邻的自有拆分文本，不重建网站元素。长文本、响应式框架页面、手机性能与站点事件保留仍需实测。

## 诊断日志

当前诊断构建标识为 `selection-diagnostics-2`，脚本版本为 `0.1.2`。用户提供的日志显示：失败时入口收到 `pointerup`，但随后 `touchend` 的 `defaultPrevented` 为真，没有产生 `click`；成功时存在 `click`，面板布局正常。是谁取消触摸事件仍待核实。入口现在对完整的主触摸轻点在 `pointerup` 打开面板，不再依赖兼容鼠标点击；过滤超过 10px 的滑动及取消手势，屏蔽随后 700ms 内的重复 `click`，新的按下操作重置去重窗口。是否在打开后立即翻译由“自动翻译”开关决定，重复点击事件不会重复请求；修复效果仍需手机复测。

1. 覆盖安装新生成的 `dist/TranslateMokey.user.js` 并刷新故障网页。
2. 复现“选中单词 → 点击翻译选区 → 面板未出现”，紧接着导出，避免后续操作挤掉日志。
3. 在“设置”点击“导出诊断日志”；面板打不开时，使用脚本管理器菜单“导出 TranslateMokey 诊断日志”。文件名为 `TranslateMokey-diagnostics.json`。
4. 若手机未下载文件，通过脚本菜单打开 TranslateMokey，进入设置底部“诊断日志”文本框，全选复制。下载失败时文本也已生成。
5. 将日志和浏览器/脚本管理器名称及版本一起提供以分析。日志仅本地导出，不自动上传。

最多保留最近 300 条，包含时间、匿名会话标识、选区长度及排除结果、捕获阶段触摸/指针/点击、按钮是否收到可信事件、焦点分类、面板开关与屏幕坐标/尺寸、视口信息、自动翻译开关、请求开始/成功，以及异常类型。不会记录原词、译文、网页 URL/标题、API Key、服务 URL、用户代理全文、DOM 内容或错误正文。日志在本管理器环境内跨网页共享；多标签页同时写日志可能相互覆盖，不保证审计完整性。存储失败时保留当前页面内存日志供导出，刷新后内存日志丢失。

“清空诊断日志”需确认，仅清除日志和当前预览，不影响设置、生词本与密钥。为定位手机事件差异，捕获阶段也记录 `touchstart` / `touchend`，但不改变原有自动翻译触发规则。

## 外部核查与设计取舍

2026-11-05 只读查询，未复制第三方代码、未调用翻译服务：

- [Tampermonkey 官方文档](https://www.tampermonkey.net/documentation.php)：核对传统存储、跨域请求、值变更监听的 API 入口。各管理器和版本的参数实际支持仍需安装核验。
- [Tampermonkey #2928](https://github.com/Tampermonkey/tampermonkey/issues/2928)：开放的重定向跨域权限与 Cookie 问题报告；作为风险线索，不视为本环境已复现。采用匿名请求、拒绝重定向并检查最终 URL，不把响应后的检查误认为可阻止已经发生的泄露。
- [Tampermonkey #2215](https://github.com/Tampermonkey/tampermonkey/issues/2215)：MV3 请求串行化报告；第一阶段仅一个活动翻译，不引入并发队列。
- [kiss-translator](https://github.com/fishjar/kiss-translator)：GitHub API 当日返回 GPL-3.0、最近推送 2026-11-04；核查其 `dev` 分支 `package.json`，使用 React/MUI 与多种文档、模型相关依赖。并检索其 selection/mobile Issues，结果不构成本项目手机兼容证据。它适合作为完整翻译产品的功能参考，但其依赖规模超出本版需要，且本仓库未明确许可证，因此不直接复制代码。本版采用原生 DOM + GM 存储与网络能力，零第三方依赖。

Index 官方鉴权、模型可用性、限额、服务条款与语言覆盖仍待核实；预设依据是 README 已记录的用户示例，而不是本次外网联调结果。
